# 拾日 Daylight

个人生活记录 PWA，适配 iPhone 和 Windows，可添加到主屏幕。当前并非 App Store 原生安装包。

## 五个入口

- **今天**：按日期查看待办、习惯、心情、三餐照片、饮水、体重和睡眠。支持隐藏首页模块、设置个人饮水目标。
- **计划**：长期目标按分钟或次数累计进度；“未来想做”收藏想去、想学、想体验和生活心愿，支持备注、可选期待日期、编辑、状态/分类筛选和标记实现。也能从快速记录添加。
- **快速记录**：记账、拍餐食、写日记、记录心情、运动、学习及健康数据。日记和心情每天一份；重复编辑会更新这一天的记录。睡眠记录归于醒来的日期。
- **回顾**：生活日历、按月的日记时间线、学习运动时长与天数、收支和支出分类。
- **我的**：主题、照片图标、自定义模块与习惯、提醒、本机应用锁、账户、JSON 备份和 CSV 导出。

## 开发与验证

需要 Node.js 22.12+ 或 24。

```sh
npm ci
npm run dev
npm run build
npx playwright install chromium
TEST_PRODUCTION=1 npm test
```

云环境已有系统 Chromium，使用 `TEST_PRODUCTION=1 CHROMIUM_PATH=/usr/bin/chromium npm test`。生产模式测试实际构建文件及离线 Service Worker。普通 `npm test` 启动开发服务，其中离线测试不运行。

## 未来想做

在“计划 → 未来想做”新增或编辑心愿，可以不设日期；期待日期只用于记录愿望，不会自动生成任务。点击“安排到某天”才会创建待办，再次调整会移动原待办，避免重复。修改心愿标题会更新已关联的待办标题；勾选待办和标记心愿实现会同步完成状态。删除心愿会保留已安排的待办，删除待办也会保留心愿。

心愿存入生活记录的 `futureWishes` 字段，沿用当前本机保存、云端同步、完整 JSON 备份及恢复路径，CSV 也包含心愿。旧记录缺少该字段时自动补为空列表，版本号保持兼容。

## 数据与同步

沿用 `daylight-v1` 本机数据键；旧版结构在加载、云端拉取及导入时补齐新版字段，不删除原有待办、日记、习惯和账目。存储无法读取时会保留原始内容并阻止覆盖，设置页提供导出原始备份。未来不兼容的数据版本也会阻止覆盖。

无演示数据。未登录时记录只在当前浏览器，清除网站数据会丢失记录；建议定期导出完整 JSON 备份。导入会替换当前记录，并在登录后上传云端。CSV 供 Excel 查看，不包含照片文件，导出的自由文本会转义表格公式前缀。完整 JSON 包含生活记录和餐食照片，不含本机锁密码、提醒与外观照片。

默认使用 `cloud-config.js` 内的个人 Supabase 公开 URL 和 publishable key。切换项目时将 `.env.example` 复制为 `.env.local`，同时填写 `VITE_SUPABASE_URL` 与 `VITE_SUPABASE_ANON_KEY`（也支持 `VITE_SUPABASE_PUBLISHABLE_KEY`）。不要使用 service-role 私钥。这些连接信息属于浏览器公开配置，记录由身份验证和 RLS 保护。

Supabase 配置：执行 `supabase.sql`，关闭公开注册，手动创建个人登录账户。登录前先备份本机记录，登录会优先使用云端版本。当前整份 JSON 同步，串行上传，不支持多设备实时合并；请避免同时编辑两台设备。在另一设备打开后刷新读取云端。已登录账户的离线修改会标记为待上传，重新打开不会被旧云端记录覆盖；联网后在“我的”选择上传本机版本，或备份后手动从云端刷新。

餐食照片在客户端压缩为 JPEG 后进入记录及 JSON 备份，受浏览器总存储容量约束。空间不足会明确报错，不会声称保存成功。大量长期照片存储以后应迁移到对象存储。

## 主题与安装

支持蝴蝶结小猫、奶油星星、照片主题。SVG 插画由本项目绘制。照片主题提供首页、头像和五个导航图标的相册替换入口；未附带从小红书或抖音搜集的照片，无照片的位置沿用插画/符号。主题偏好和外观照片只保存在本机，不会写入生活记录或上传到 Supabase。

iPhone 使用 Safari 的“分享 → 添加到主屏幕”；Windows 使用 Edge / Chrome 的安装网站功能。安装后的本机存储可能与浏览器不同，需要登录同一账户，先备份未上传记录。

构建脚本生成带版本的 Service Worker，仅缓存静态应用文件，不缓存身份验证或云端数据请求。首次联网完成缓存后可离线打开。新版本等待旧窗口全部关闭后激活，避免中途刷新丢失输入；更新后请关闭所有拾日窗口再重新打开。不需要删除主屏幕图标或清除网站数据。

修改图标 SVG 后，可使用 `CHROMIUM_PATH=/usr/bin/chromium node scripts/make-icons.mjs` 重新生成已提交的 PNG 图标。

## 提醒和应用锁的范围

提醒只在应用处于前台时检查，达到当天设定时间后展示一次。关闭应用后没有后台系统通知；原生通知和 iOS Face ID 尚未实现。

应用锁是本设备6位数字界面锁，使用随机盐和 PBKDF2-SHA256 存储验证结果，密码不会明文保存或上传。连续错误会暂时限制尝试。重新打开及回到前台（离开超过1分钟）需要解锁。它不加密生活记录，不防止能访问浏览器存储的人读取数据，也不是 Face ID。请记好密码，清除网站数据会同时清除锁和未同步记录。

实际账户和真机 iOS 的同步、相机权限、主屏幕安装仍需在用户设备验证；自动化云端流程使用模拟测试账户和响应，不宣称已代替用户登录验证。
